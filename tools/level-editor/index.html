    Keyboard shortcuts

    1-7Tile brush: floor, wall, water, ice, crack, plate, decor
    B R G IPaint, rectangle fill, flood fill, eyedropper (Alt+click also picks)
    E O VPlace enemy, place object, select / move
    Right clickBrushes: paint floor. Enemy / Object / Select: delete the thing on that tile
    Del / BackspaceDelete the selected enemy / object
    Arrow keysMove the selected enemy / object one tile
    EscDeselect, close dialogs
    [ ]Previous / next room tab
    - =Zoom out / in
    L F MToggle grid, game features (door gaps, locks, stairs), mage sprite
    KCheck the level
    Ctrl+Z / Ctrl+YUndo / redo (also Ctrl+Shift+Z)
    Ctrl+S / Ctrl+OSave / open
    ?This help

    Door gaps, locks, seals and the lair stairs are placed by the game; with Game features on they are drawn as they will appear, outlined in green (doors), amber (lock / seal / crack) and violet (stairs). The mage can be dragged with the Select tool.
